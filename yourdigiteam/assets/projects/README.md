# Project screenshots

The Featured Projects filmstrip on `web-development.html` shows a screenshot of
each client's site as the card's resting face. On hover the card floods to its
accent colour and the write-up appears.

## Adding a screenshot

Drop the file in here using the exact name below. Until it exists, the card
falls back to generated artwork in that project's colours — the strip never
shows a broken image.

## What the files should be

- **Roughly 3:2, landscape.** The card crops to fill, centred, so anything
  close to that ratio works. 1200x800 is plenty.
- **A real screenshot of the live site**, not a mockup in a laptop frame —
  the card is already a frame.
- **The hero / above-the-fold area** reads best. A full-page screenshot
  scaled down turns into unreadable stripes.
- **JPG at 70-80% quality**, ideally under 250KB each. There are nine of
  them and they all load on the same page.
- The card darkens the image slightly so the overlaid text stays legible, so
  do not pre-darken them yourself.
